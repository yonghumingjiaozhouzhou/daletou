# 大乐透历史数据统计与号码生成工具（Streamlit）

本工具用于大乐透（前区 1-35 选 5，后区 1-12 选 2）历史开奖数据的统计分析与号码组合生成。
**仅作历史数据统计娱乐用途，开奖完全随机，无法预测。**

## 运行方式

方式一（推荐，Windows 双击）：

1. 双击 `run.bat`。

方式二（命令行）：

```bash
pip install -r requirements.txt
streamlit run daletou_app.py
```

浏览器会自动打开 `http://localhost:8501`。

## 功能一览

### 侧边栏（全局参数）
- **数据管理**：导入历史开奖数据（CSV/Excel，自动校验重复期号、号码范围）、手动录入单期、清空数据库、导出开奖记录 Excel、下载导入模板
- **统计期数范围**：滑动条选择近 N 期（10 期起），或勾选统计全部历史
- 参数选择自动保存到本地（`data/preferences.json`），下次打开页面自动加载

### 主界面 7 个功能页（顶部导航：一行 4 个，多余的换行）
1. **开奖历史数据**：全量期号 / 日期 / 前区 5 码 / 后区 2 码，自动计算前区和值、奇偶数量、三区分布；按期号模糊检索；导出 Excel
2. **号码统计分析**：前区 / 后区出现频次柱状图（热号红、温号灰、冷号蓝）、前区奇偶组合占比饼图、三区出号数量分布柱状图、汇总指标卡片（平均和值、连号出现率、最长连号、前后区重号概率）
3. **号码组合生成器**（左侧「号码生成参考」参数区 + 右侧结果区，横竖均匀分布）：
   - 号码策略：纯随机 / 热号优先 / **温号优先** / 冷号优先 / **冷热温混合**（可分别设置热号 / 温号 / 冷号数量）
   - 投注类型：单式 / 复式 / 胆拖
     - 单式：按参数生成 N 注，自动校验奇偶 / 三区约束（不满足自动重新生成）
     - 复式：前区选 6-18 个、后区选 3-12 个，自动计算注数（C(前区,5)×C(后区,2)）与金额
     - 胆拖：前区胆码 **0-4** 个（0=无胆全拖）+ 拖码、后区胆码 0/1 个 + 拖码（无胆时拖码最低 **2** 个），自动计算注数与金额
   - 生成 2 注以上单式后，可一键**转化为复式或胆拖**（合并去重 / 按出现频次取胆，前区胆码 0-4），注数与金额自动重算
   - 每次生成都显示**总注数与总金额**（2 元/注）；一键复制全部号码；导出 Excel / txt
   - **每次生成自动写入「生成历史记录」**（含生成时间、生成时最新开奖期号）
4. **高级统计**：和值分布直方图、连号统计（无连号 / 二连号 / 三连号 / 四连号及以上）、上期重号统计（前后区）、号码遗漏值统计（距上次开出间隔期数，按冷热配色）、多工作表统计报表 Excel 导出
5. **后区分析与走势**：后区频次（冷热配色）、奇偶分布、大小分布（小 1-6 / 大 7-12）、两码组合频次 Top10、后区遗漏值、后区号码走势图（可选最近 10-100 期），以及平均后区和值 / 重号概率 / 奇偶占比 / 大小占比指标卡
6. **生成历史记录**：自动记录每次生成的号码（生成时间、生成时开奖期数、投注类型、注数 / 金额）。记录对应期已开奖时（对照期为生成后的第一期开奖结果），命中号码以**实心圆标出**（前区红 ●、后区蓝 ●），并显示命中数量、中奖等级（一至九等奖，按大乐透官方奖级设置）与中奖金额（一、二等奖为浮动奖金，标注以官方公布为准；三~九等奖按固定奖金额计算）；支持筛选（全部 / 已开奖 / 待开奖 / 仅中奖）、导出 Excel、清空历史
7. **号码走势图**：参考彩票走势图样式——期次 × 号码矩阵（前区 1-35、后区 1-12，含星期列），当期开出号码以红（前区）/ 蓝（后区）圆圈标注，未开出格填充该号码当期连续未出现期数，底部统计各号码**出现次数 / 平均遗漏 / 最大遗漏 / 最大连出**；走势期数可调（10-100 期）
8. **90注定位**：一键随机生成 **5 组 6+3** 号码（每组 18 注，共 90 注 / 180 元），置于 **9×5 表格**（前区 6 行 + 后区 3 行 × 5 组）；开奖后以生成后第一期结果为对照，命中位置在 9×5 表中填充颜色（前区红 / 后区蓝）；功能内独立的**历史生成记录**（时间、期号、号码、命中状态、命中数，可导出 Excel / 清空）；另设空白 **9×5 命中位置统计总表**，累计有记录以来各位置命中次数，次数越高颜色越深（深红为最多）

## 数据说明

- 首次运行且数据库为空时，会自动写入 150 期**随机生成的示例数据**（非真实开奖），页面上会明确提示。可在左侧「数据管理」导入真实数据，或清空后手动录入。
- 数据库为本地 SQLite 文件：`data/lottery.db`。
- 导入格式支持两种：
  1. 期号 + 日期 + 前区号码字符串 + 后区号码字符串（空格/逗号分隔），如：`26001,2026-09-14,"01 05 12 23 34","03 08"`
  2. 期号 + 日期 + 前区1~前区5 + 后区1~后区2 分列（列名如 `前区1`…`前区5`、`后区1`、`后区2`）
- 也可在左侧下载导入模板 CSV 参考格式。

## 文件结构

```
daletou_stats_app/

├── daletou_core.py     # 核心逻辑（数据库、统计、生成器、导入导出）
├── test_core.py        # 核心逻辑测试（python test_core.py）
├── requirements.txt    # 依赖
├── run.bat             # Windows 一键启动
└── data/               # 运行时自动创建（SQLite 数据库、偏好缓存）
```
